# 13 · Glossary — everything explained from scratch

| Term | Simple meaning |
| --- | --- |
| MVP | Minimum viable product: the smallest version real users can actually use and get value from. |
| SaaS | Software as a service: customers pay a subscription to use it online. One platform serves many customers. |
| Multi-tenant | Each customer (clinic) has its own separate space inside the same software. |
| B2B2C | We sell to a business (clinic) that offers the product to its consumers (women) for free. |
| PCOS | Polycystic ovary syndrome: a common hormone condition; signs include irregular periods, acne, excess hair growth. |
| Endometriosis | Tissue like the womb lining grows outside the womb, often causing severe period pain; often recognised late. |
| GDM | Gestational diabetes: high blood sugar first found in pregnancy; raises later risk of type 2 diabetes. |
| OGTT | Oral glucose tolerance test: drink a sugar drink, blood sugar measured after 2 hours. |
| Care gap | A check or follow-up that guidelines recommend but has not happened yet. |
| Red flag | A symptom that needs urgent care, shown before anything else (UAE ambulance 998). |
| Rule engine | Code that applies clear if-then rules (e.g. "2 of the last 6 cycles longer than 35 days"). Transparent and testable. |
| LLM | Large language model: AI that writes and understands text (e.g. Claude). We use it to explain, not to decide. |
| RAG | Retrieval-augmented generation: AI first finds trusted documents, then answers only from them, with citations. |
| Embedding / vector | A list of numbers that captures meaning, so similar text can be found quickly. |
| pgvector | A Postgres add-on that stores embeddings and searches them. |
| Agent / LangGraph | An agent is an AI step with one job; LangGraph connects agents into a controlled flow. |
| JSON schema | A strict template the AI's answer must fit, so the app can trust the format. |
| Guardrail | A check that blocks unsafe output (e.g. the words "you have PCOS"). |
| Passkey | Login with Face ID or fingerprint instead of a password. |
| RLS | Row-level security: the database itself decides which rows each user may see. |
| Audit log | A record of who saw or changed what, and when. |
| FHIR | The global standard format for sharing health records between systems. |
| Malaffi | Abu Dhabi's health information exchange connecting nearly all facilities. |
| ADHICS | Abu Dhabi's mandatory healthcare cybersecurity standard. |
| Synthetic data | Realistic but completely fake data made by software; no real person behind it. |
| Lighthouse | Google's tool that scores a website's speed and accessibility. |
| RTL | Right-to-left layout, used for Arabic. |
